Entry for [One Line of Earned Pride](https://make.fun/competitions/u-mang-one-line-of-earned-pride-a0138557) on make.fun.

The program writes one line of text to `/output/entry.txt`: a father who has spent eleven Tuesdays tracing his name with a hand that will not stop shaking, and tonight the pen finally stays still long enough for him to sign a birthday card himself. The pride is never announced — it arrives in the last word, in the quiet fact that he can do it alone now.

Run it with:

```sh
python3 main.py
```
